# HABITAT HUNT - A GAME OF ANIMAL GEOGRAPHY

# DESCRIPTION

This is an educational game developed at the University of Strathclyde under CS408.

## Local Runtime Guidance

1. Check if node and npm are installed by using 'node -v' and 'npm -v'
2. If they are not installed, use 'npm install' and follow the link below to install node
   https://nodejs.org/

1. Open the terminal and run 'npm run dev'
2. Open the localhost link and enjoy
